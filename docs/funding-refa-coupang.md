# 越境EC（ReFa / Dyson / Brighte）× 韓国Coupang ── 事業計画と資金の考え方

> **rev.4（2026-09-12）**：「無在庫・仕入代金の先払い不要・HP掲載商品はすべて51%・定価で出品」という前提を反映して作り直した。
>
> **この前提は3つとも成立します。ただし最初の2つが成立すると、rev.1〜3 が組み立てていた「運転資金¥20,000,000」という調達理由そのものが消えます。** 本版はそこを正面から扱う。

---

## 0. 前提確認の結論

| 前提 | 判定 | 何が起きるか |
|---|---|---|
| ① 無在庫（受注発注） | **○ 成立する** | Coupang Global は出荷リードタイムを自己申告でき、さらに6営業日のバッファが自動付与される。ただし**欠品キャンセルがセラースコアに直撃**する（→ §1） |
| ② 仕入代金の先払い不要 | **○ 成立するなら決定的** | **CCC 90日が消滅 → 運転資金が不要になる**（→ §2） |
| ③ HP掲載商品すべて51% | **○ 前提として扱う** | 対象カタログがMTG ONLINESHOP全体に広がる。スプレッドシートの列は「定価の50%」なので、**51%か50%かは要確定**（1%＝定価¥50,000で¥500の差） |
| ④ 定価で出品 | **△ 成立するが、固定すべきでない** | 粗利率は一律30〜35%で成立。ただし唯一実測できたSKUでは定価出品は市場より**+31%**高く、売れない（→ §3, §4） |

### 一番大事な結論

**①②が本当なら、¥20,000,000の資金調達は不要です。**

在庫を持たず、仕入代金も先に払わないなら、埋めるべきキャッシュギャップがありません。rev.1〜3 の資金使途は「在庫を先に買うから90日分の現金が寝る」でした。その前提が消えた以上、同じ理屈で調達を申し込むと**出資者に前提を突かれた瞬間に破綻します**。

**やるべきは、まず自己資金で10〜30 SKUを出して韓国の実売価格を検証すること。** 無在庫なら、それがほぼゼロコストでできます。調達はその後、**「売れると分かった後にオペレーションを拡大するため」**に、性格を変えて取るべきです（→ §7）。

## 1. 前提① 無在庫（受注発注）── 成立する。ただし生命線がある

### 成立する理由

- Coupang Global Marketplace では、**出荷リードタイムを出品時に自己申告**する
- Coupangが**さらに6営業日のバッファを自動で上乗せ**して顧客表示の配送予定日を作る（日曜・祝日を除く）
- **グローバルセラーについては「出荷の遅れ」自体はセラースコアに影響しない**

受注 → MTGへ発注 → 自社着荷 → 検品 → 韓国へ発送、という流れでも、正直なリードタイムを申告していれば構造的に許容されています。

**想定リードタイム**

| 工程 | 日数 |
|---|---|
| Coupang受注 → MTGへ発注・着荷 | 2〜4日 |
| 検品・梱包・韓国語同梱物 | 1日 |
| 日本 → 韓国 国際配送・受領 | 3〜5日 |
| **合計** | **6〜10日** |

### ⚠ 生命線：欠品キャンセル

**Coupangは「品切れによる注文キャンセル」を、誰がキャンセルしたかに関わらずセラースコアに反映します。** スコアが下がると出品停止、さらにアカウント停止まで行きます。

無在庫モデルは、ここだけが致命傷になり得ます。そしてスプレッドシートの実データは、それが絵空事でないことを示しています。

| 在庫状況 | SKU数 | 比率 |
|---|---:|---:|
| 在庫あり | 1,426 | 92.5% |
| 在庫なし | 71 | 4.6% |
| 不明 | 45 | 2.9% |
| **在庫なし＋不明** | **116** | **7.5%** |

**2026-08-26時点で、カタログの7.5%が引けない状態です。** HP掲載商品を全部出品して在庫同期をしなければ、受注のうち相当数が欠品キャンセルになります。

> **これが Compass（在庫同期・自動出品システム）の存在理由そのものです。** 無在庫モデルにおいて在庫同期は「あると便利な機能」ではなく「事業が死なないための必須インフラ」。エクイティのストーリーを立てるなら、ここが芯になります（→ §7）。

### その他の運用上の論点

- MTG ONLINESHOP は国内発送のみと思われるため、**日本の自社住所を経由する二段階**になる。直送はできない前提で設計する
- 返品受付住所も日本国内でよい（Coupang Global の仕様）
- 無在庫でも**1件ごとに検品・梱包・発送の作業が発生**する。月300件なら1日10件で1人で回るが、月1,000件は仕組みが要る。**ボトルネックは資金ではなく作業量**

## 2. 前提② 先払い不要 ── CCC が消滅する

### 従来モデル（rev.1〜3が前提にしていたもの）

```
D0   仕入代金を支払う        ← 現金が出る
     …在庫を持つ…
D90  Coupang入金             ← 現金が戻る
= 90日ぶんの資金拘束。月1,000個なら常時3ヶ月分が寝る
```

### 無在庫＋後払いモデル

```
D0    Coupangで受注（売上が確定してから動く）
D0-4  MTGへ発注・着荷
D4-5  検品・梱包
D5-10 韓国へ配送・受領
D40   Coupang入金（当月締め → 翌月第15営業日）
D50   MTGへ支払い（月末締め翌月末払いの場合）
= 入金が支払いより10日先行。資金拘束ゼロ
```

**仕入が後払いなら、Coupangからの入金がMTGへの支払いより先に来ます。** 拘束される現金はありません。それどころか一時的に現金が積み上がります。

### したがって

| 資金使途 | 従来の想定 | 無在庫＋後払いなら |
|---|---:|---:|
| 在庫仕入資金 | ¥14,000,000 | **¥0** |
| 仕入代金の立替 | 含む | **¥0〜少額** |
| 国際物流の立替 | ¥1,600,000 | 売上に連動・少額 |
| **運転資金の必要額** | **¥16,000,000** | **ほぼゼロ** |

**「運転資金が要るから貸してほしい」は、この前提では言えません。** 出資者に説明する理屈を根本から変える必要があります。

> **要確認**：MTGとの支払条件が本当に後払い（掛け）か。前払いなら、受注から入金までの約40日ぶんだけ立替が発生します。月300件・平均仕入¥15,000なら **¥15,000 × 300 × 1.3ヶ月 ≒ ¥5,850,000** が必要。ここは契約書で確定させてください。

**粗利率は定価に関係なくほぼ一律30〜35%。** そして **1個1万〜1.5万円は、定価¥30,000〜45,000のSKUで達成できます。** 前提③④のもとでは、当初のお話は数字として完全に成立します。

### ただし「定価固定」は捨ててください

51%仕入の本当の価値は「定価で売れること」ではなく、**値下げ余地**です。

| 定価 | 損益分岐となる出品価格 | **値下げできる幅** |
|---:|---:|---:|
| ¥18,480 | 定価の65.1% | **35%引きまで** |
| ¥25,190 | 定価の63.3% | **37%引きまで** |
| ¥39,180 | 定価の61.5% | **39%引きまで** |
| ¥54,780 | 定価の60.6% | **39%引きまで** |
| ¥75,000 | 定価の60.0% | **40%引きまで** |

**定価の約60〜65%が損益分岐。つまり35〜40%引きまで粗利が残ります。** これは韓国市場での価格競争力そのものです。「定価で出す」と決め打つと、この武器を使わずに機会を落とします。**正しい設計は「定価の65〜100%のレンジで、SKUごとに韓国の相場に合わせる」**です。

## 4. ⚠ 唯一の実測データが、定価出品を否定している

韓国での実売を実測できたSKUは1つだけで、その結果がこうです。

| | 値 |
|---|---|
| リファカラットレイフェイス 定価 | ¥25,190 |
| **定価で出品した場合** | **₩239,305** |
| 韓国の直購実勢 | ₩134,410 〜 ₩183,000 |
| 実勢の上限に対して | **+31%** |
| 損益分岐（定価の63.3%） | ₩151,423 |

**定価出品では市場より31%高く、売れません。** ただし損益分岐は ₩151,423 なので、**₩165,000〜183,000 のレンジで出せば粗利は ¥1,500〜3,200 残ります。** 売れないのは「定価で出すこと」であって、「このSKUで商売が成立しないこと」ではありません。

この1件が示す教訓は明快です。

> **定価は出発点であって、着地点ではない。SKUごとに韓国の相場を測り、定価の65〜100%の間のどこで出すかを決める。それが粗利を決める。**

そして、ファインバブル・日傘・バイタルウェア・OnTrac について韓国の相場は**まだ測っていません**。§3の粗利はすべて「定価で売れたら」の数字です。**ここが本資料に残る唯一にして最大の未検証項目です。**

## 5. 商品選定（rev.3から変更なし）

無在庫でも定価出品でも、**220Vの壁は動きません**。実データ1,542 SKUの分析結果はそのまま有効です。

| 値入れ（定価−仕入）の帯 | SKU数 | 韓国で売れない割合 |
|---|---:|---:|
| 〜¥5,000 | 824 | 1.7% |
| ¥5,000〜10,000 | 255 | 9.0% |
| ¥10,000〜20,000 | 335 | 44.2% |
| ¥20,000以上 | 128 | **63.3%** |
| （¥30,000以上） | 38 | **73.7%** |

値入れが大きいのはドライヤー・ヘアアイロン・掃除機・空気清浄機・照明 ＝ すべて100V AC直結。韓国は220Vで動きません。

**スクリーニング：1,542 → 1,091 SKU**（100V・大型 −266／在庫なし・不明 −81／会員限定・定期・予約 −104）。

**3つの柱**

| 柱 | 中身 | 定価帯 | 定価出品時の粗利 |
|---|---|---|---|
| **1. リファ ファインバブル** | シャワーヘッド。非電気・約350g・故障モードほぼなし | ¥18,000〜78,000 | ¥5,470〜27,370 |
| **2. Dyson OnTrac ヘッドホン** | Dyson 60 SKU中、電圧の壁を越えられるほぼ唯一の高単価品 | ¥54,780 | ¥18,895 |
| **3. バイタルウェア／リネン／日傘／シルク** | 非電気・軽量・破損しない。SKU数480件 | ¥7,700〜44,330 | ¥1,710〜15,080 |

**無在庫だと、この3つの柱に絞る必要すらありません。** 在庫リスクがないので、1,091 SKUを全部出して売れたものを残せばいい。**むしろ「全部出す」が無在庫モデルの正解**で、そのためには在庫同期が必須という話に戻ります。

> 除外した100V製品225 SKU は**台湾（110V・Aプラグ）なら生きます**。定価¥40,000級で粗利¥13,000超。ただし韓国と同時に立ち上げるべきではありません。

## 6. 必要な資金は、性格も桁も変わる

### 要らなくなったもの

| 項目 | 従来 | 無在庫＋後払い |
|---|---:|---:|
| 在庫仕入資金 | ¥14,000,000 | **¥0** |
| 物流・手数料の立替 | ¥2,000,000 | 売上連動・少額 |

### 本当に要るもの

| 項目 | 金額 | 内容 |
|---|---:|---|
| 出品オペレーション | ¥1,200,000 | 1,091 SKUの撮影・韓国語化・カテゴリマッピング・登録 |
| **在庫同期システム（Compass）** | ¥1,500,000 | **無在庫モデルの生命線。MTG在庫 ↔ Coupang出品の自動同期** |
| 韓国語CS・受注処理 | ¥900,000 | 立ち上げ6ヶ月分 |
| 広告・初期露出 | ¥600,000 | |
| 返品・為替・精算繰越のバッファ | ¥800,000 | Coupangは月100万KRW未満は翌月繰越 |
| **計** | **¥5,000,000** | |

**運転資金¥20,000,000 → 立ち上げ・オペレーション資金¥5,000,000。** 用途も金額も別物です。

### 調達手段の結論も変わる

| | 従来（在庫買取） | 無在庫 |
|---|---|---|
| 資金の性格 | 運転資金 | 立ち上げ・開発費 |
| 担保 | **在庫（実物資産）** | **なし** |
| 適した手段 | **貸付型**（在庫担保・年利10〜12%） | 貸付は担保がなく通りにくい |
| エクイティの正当性 | 弱い（90日の立替に株は高すぎる） | **Compass に対してなら成立** |

**皮肉なことに、無在庫にすると「借入で取る」という前回までの推奨が使えなくなります。** 在庫という担保が消えるからです。残るのは次の2つです。

**A. そもそも調達しない（推奨）**
無在庫なら、10〜30 SKUを自己資金で出品して韓国の実売を検証できます。コストは撮影・翻訳・登録の作業時間がほぼすべて。**まずこれをやってください。** §4の未検証項目がここで潰れます。

**B. Compass に対するエクイティ**
「ReFaの物販は、Coupang越境ECの在庫同期・自動出品フローを自社で実証するため。売り物はその先の Compass（システム＋フランチャイズ）」──**無在庫モデルは、このストーリーを前より強くします。** 在庫同期が必須インフラであることが、無在庫であるがゆえに自明だからです。

## 7. 進め方（改訂）

| フェーズ | 期間 | やること | 資金 | 判定 |
|---|---|---|---|---|
| **0. 検証** | D0–60 | Coupang Global 登録／**10〜30 SKUを出品して韓国実売価格と受注を実測**／欠品キャンセル率を測る | **自己資金・ほぼゼロ** | 受注が入るか／定価の何%で売れるか |
| **1. 拡大** | D61–150 | 在庫同期の仕組みを作り、SKUを300〜1,091へ拡張 | ¥2,000,000 | 月100件・粗利率25%以上 |
| **2. 本格化** | D151–365 | 韓国語CS体制／広告／Compass製品化 | ¥3,000,000 | 月500件・月次黒字 |

**フェーズ0を飛ばさないでください。** 無在庫の最大の利点は「ほぼタダで検証できること」です。ここで韓国の実売価格が取れれば、§3の粗利表が推定から実測に変わり、そこで初めて調達の話が意味を持ちます。

## 8. 実行前に潰すこと（優先順）

1. **MTGとの支払条件**（前払いか掛けか、サイト日数）── §2の全体がここに乗っている
2. **掛け率が51%か50%か**、適用条件（最低発注数量の有無）── スプレッドシートの列は「定価の50%」
3. **卸契約に越境販売・海外転売・再販地域の制限条項がないか**
4. **MTGが在庫APIまたは在庫データを提供できるか**（無在庫モデルの生命線。なければスクレイピング等の代替手段の可否）
5. **柱1〜3のSKUの韓国直購実勢価格を実測**し、§3の「定価の65〜100%」のどこに着地するかを決める
6. MTG ONLINESHOP が**法人向けに直接韓国へ発送できるか**（できれば二段階配送が不要になり送料と日数が減る）
7. Dyson OnTrac の**充電器が100-240V対応か**を現物確認
8. リファ ファインバブルの**韓国の給水ホース規格（G1/2）互換性**
9. 会員限定14／定期購入45／予約48 SKU の**転売可否**
10. 輸出免税による仕入消費税の還付可否（税理士確認）／韓国の関税率（HSコード別）／為替レートの実勢値更新
