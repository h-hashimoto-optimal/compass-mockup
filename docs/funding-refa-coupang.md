## 0. 結論を先に

**資金使途の立て方（在庫を先に買う運転資金）は正しい。単価経済性も成立する。ただし「1個あたり10,000〜15,000円」だけは、算数上どうしても出ません。**

| | 初版の誤り | rev.2（訂正後） |
|---|---:|---:|
| 韓国販売価格 | ₩165,000 | ₩180,000〜238,000 |
| 粗利／個 | ¥1,709 | **¥3,091〜8,433** |
| 粗利率 | 9.8% | **16〜34%（基本 25%）** |

**なぜ「掛け率51%」が「粗利25%」になるのか。** 掛け率と粗利率は別物です。掛け率51%は「定価で売れたら値入れ49%」という意味で、そこから売価に対する手数料・物流・返品が引かれます（§4に分解表）。

**なぜ1個1万〜1.5万円は出ないのか。** 掛け率51%なら粗利の理論上限は定価の49%。手数料12.5%と物流¥1,350を差し引いた実務式は、韓国売値を日本定価の95%と置くと：

```
粗利 ≒ 0.83 × 日本定価(税抜) − 0.51 × 日本定価(税抜) − 1,350
     ≒ 0.32 × 日本定価(税抜) − 1,350
```

| 目標粗利 | 必要な日本定価（税抜） |
|---:|---:|
| ¥5,000 | ¥19,800 |
| ¥8,000 | ¥29,200 |
| **¥10,000** | **¥35,500** |
| **¥15,000** | **¥51,100** |

つまり **1個1万〜1.5万円は、定価¥35,000〜51,000クラスの商品でしか出ません。** これはリファ ビューテック ドライヤーやダイソンの価格帯です。そしてそれらは日本仕様100Vで、**韓国（220V）では売れません**（§2）。

**これが事業設計の本当の論点です。**

- 粗利の大きい商品（ドライヤー・ダイソン、定価¥40,000超）→ 韓国では動かない
- 韓国で売れる商品（カラット系ローラー、定価¥21,450〜33,000）→ 1個 ¥3,100〜8,400

**韓国 × カラット系に絞るなら、1個¥5,000前後 × 高回転で取りにいく。**
**ドライヤー級を売りたいなら、韓国ではなく台湾（110V・Aプラグ、日本の100V機器がほぼそのまま使える）を検討すべきです。**（§11）

そして粗利率25%で資本が年4回転するなら、**投下資本利益率は年150%超**。この規模になると、ボトルネックはもはやマージンではなく**数量**です。月440個売れるのか ── そこが唯一の検証対象になります（§6.5）。

## 2. なぜ「リファ カラット系」に絞るのか（ダイソン・ブライトを外す理由）

### 電気製品は韓国向けに構造的に向かない

| | 日本仕様 | 韓国 | 帰結 |
|---|---|---|---|
| 電源電圧 | 100V | **220V / 60Hz** | 日本仕様のドライヤー・ヘアアイロンは**そのまま使えない** |
| プラグ形状 | Aタイプ | **C / Fタイプ** | 変換＋変圧器が必須 |

ダイソンのドライヤー、リファ ビューテック ドライヤー／ストレートアイロンは、いずれも日本仕様が100V。韓国の購入者が変圧器なしで使うと動かないか故障します。**返品率とレビュー評価が壊れ、Coupangのアカウント健全性スコアに直撃します。** ここは規制の問題ではなく物理の問題なので、書類でも交渉でも回避できません。

### 一方、リファ カラット系は非電気製品

- 電源なし・電池なし。**ソーラーパネルでマイクロカレントを発生させる構造**
- IPX7防水
- → 電気用品安全法（韓国KC）・電波法の対象外。変圧器不要。故障モードがほぼない

なお韓国の海外直購（해외직구）では、電気用品であっても**個人の自家使用目的なら「モデル別1個」までKC認証が免除**され、別途申請も不要です。つまり**規制上は電気製品も通ります**。しかし通関を通っても**製品が動かない**のでは意味がありません。この2つを混同しないことが重要です。

> リポジトリ内の `docs/onboarding-coupang-global.md` §7 は「電気電子製品はKC対象なので初期は避ける」と書いていますが、Global Marketplace（해외직구）ルートでは自家使用免除が効くため、厳密にはKCが障壁ではありません。**実際の障壁は電圧です。** 加盟店向け資料としてこの点は補正したほうが正確です。

### $150 免税枠が価格の上限を決める

韓国の海外直購は、課税価格 **$150以下**なら関税・付加価値税が免除されます（目録通関）。1ドル未満でも超えると全額に課税されます。

| 価格 | ドル換算（@₩1,400） | 買い手の負担 |
|---:|---:|---|
| ₩205,000 | $146 | **免税** |
| ₩210,000 | $150 | 境界 |
| ₩214,200 | $153 | 関税8% + VAT10%（約₩38,000増） |
| ₩238,000 | $170 | 同上 |

つまり **₩210,000 が直購チャネルの実質的な価格上限**です。これを超えると買い手の実負担が跳ね上がり、韓国国内モール（関税込み・国内配送）に対する価格優位が消えます。**販売価格は ₩205,000 前後に設計上ロックすべき**です。

> 注：目録通関と一般輸入申告で「海外配送料を課税価格に算入するか」の扱いが異なります。実運用前に関税庁の予想税額照会で要確認。

## 3. 韓国市場の実勢価格 ── チャネルを分けて読む

初版で最大の誤りがここでした。**韓国のリファ価格は、チャネルによって2層に分かれています。**

### A層：韓国国内モール（関税・VAT込み、国内配送）

| 販売元 | SKU | 価格 |
|---|---|---:|
| 신세계몰 | ReFa CARAT FACE | **₩238,000**（최적가 ₩214,200） |
| SSG | MTG ReFa CARAT FACE | **₩207,400**（최고판매가 ₩267,600） |

**≒ ¥21,800〜25,000。日本の定価（¥23,800税抜 / ¥26,180税込）とほぼ同水準です。**
ここは正規輸入業者（MTG韓国唯一の公式代理店ほか）の領域で、直接の競合ではありません。

### B層：海外直購・並行輸入（買い手が関税負担、日本から発送）

| 価格 | 円換算 | SKU |
|---:|---:|---|
| ₩74,300 | ¥7,821 | CARAT RAY FACE ／ 真贋要確認 |
| ₩101,300 | ¥10,663 | CARAT RAY FACE |
| ₩134,410 | ¥14,148 | CARAT RAY FACE |
| ₩169,400 | ¥17,832 | CARAT RAY FACE |
| ₩183,000 | ¥19,263 | CARAT RAY FACE |

**あなたが出すのはB層（Coupang Global Marketplace）です。** ただし上記B層の価格はすべて **CARAT RAY FACE**（下位モデル）のもので、CARAT / CARAT FACE の直購価格ではありません。

**わかること：**

1. A層（₩207,400〜238,000）とB層の間に、**₩180,000〜205,000 のレンジが空いている可能性がある。** 直購の価格優位を出しつつ免税枠にも収まる帯。ここが狙い所。
2. ただし **B層の実勢はSKU別に実測が必要**。CARAT RAY FACEの直購が₩134,410まで落ちていることを見ると、CARAT / CARAT FACEも同程度の下押し圧力を受けている可能性がある。
3. 下限層（₩74,300、₩101,300）は仕入原価 ¥12,138（≒₩115,300）を割っている。**この層とは価格で戦えません。**
4. MTG自身が**偽造品への注意喚起**を出しており、KREAMは「偽物なら購入価格の3倍補償」を打ち出しています。**韓国市場では「正規品であること」に値段がついている。**

→ **51%の正規卸口座は、単なる仕入ルートではなく、インボイスを提示できる中〜上位帯を取るための差別化資産です。** Coupangの知的財産権ポリシーは出品者に仕入インボイスまたは権利者許諾の提出を求められるので、これは守りであると同時に攻めの材料になります。

## 5. なぜ資金が要るのか ── CCC（現金が戻ってくるまでの日数）

**これが資金使途の全部です。**

```
D0     仕入代金を支払う（前払い）           ← ここで現金が出ていく
D0-14  メーカー/卸からの入荷リードタイム
D14-21 検品・撮影・韓国語化・Coupang登録
D21-51 在庫滞留（平均30日で販売）
D51    販売成立
D51-56 韓国へ国際配送・受領
D56-90 Coupang精算（当月売上 → 翌月第15営業日に入金）
D90    入金                                ← ここで現金が戻る
```

**仕入から入金まで、約90日。** さらにCoupangは月次精算・月100万KRW未満は翌月繰越なので、立ち上がり期はさらに伸びます。

**つまり：**

- 月に1,000個売る体制を作るには、**常時3ヶ月分＝3,000個分の仕入代金が寝ている**必要がある
- 3,000個 × ¥12,138 = **¥36,414,000**
- これは売上が増えるほど**増える**（成長するほど資金が足りなくなる典型的な運転資金型ビジネス）

**在庫は実物資産として残ります。** 最悪の場合でも日本国内で処分売りして原価の相当部分を回収できる。出資者から見て、これは損失が青天井にならないということです。

## 6. 調達の設計

### 6.1 これは本来「借入」の案件です

資金使途が運転資金の立替だけなら、**エクイティ（出資）は調達手段として不利**です。

- 出資者から見て：物販に株で入る理由がない。年利10〜15%で貸したほうがリスク調整後リターンが良い
- あなたから見て：90日の立替の対価に、将来利益の永久分配は高すぎる

**しかも rev.2 で粗利率が25%に上がったことで、この論点はさらに強くなりました。** 投下資本利益率が年150%超なら、**年利10〜15%の借入で調達して差額を全部自分で取るのが圧倒的に合理的**です。株を渡す理由が事実上なくなります。

投資家には「なぜ銀行や日本政策金融公庫ではなく、うちなんですか？」と必ず聞かれます。

| | ストーリー |
|---|---|
| **A. 借入で取る（推奨）** | 「銀行は実績のない越境ECに在庫担保で貸さない。最初の1年の実績を作るための**つなぎ**として借りたい。実績ができたら銀行に借り換える」 |
| **B. 出資で取る** | 「リファの物販は**単体で儲けるためにやるのではない**。Coupang越境ECの運用フローを自社で回して実証し、それを Compass（システム＋フランチャイズ）として他の事業者に売る。**物販は実証エンジンで、売り物はその先のシステム**」 |

「資金使途だけ」に絞るなら **A**。出資を取りたいなら **B** に戻る必要があります。

### 6.5 ⚠ 本当のボトルネックは数量です

**rev.2 で粗利が上振れた結果、リスクの所在が移りました。**

年間5,272個 ＝ **月440個**。これは韓国のリファ カラット市場に対して小さくない数字です。

- 価格弾力性を無視しています。**自分で月440個を流し込めば、B層の価格を自分で崩します**
- 現在のB層の出品者数・アイテムウィナー・推定販売数量は未測定
- 5,272個を吸収できなければ、回転数が落ちてCCCが伸び、必要運転資金がさらに増えます

**したがって、トランシェ1の90日で測るべき最重要指標は「粗利率」ではなく「消化速度」です。** 200個を90日で消化できるか（＝月67個）。これが出れば月440個は現実的な射程に入ります。出なければ、調達額を下げるか、SKUを増やして1SKUあたりの数量を分散させる必要があります。

## 11. 検討すべき2つの分岐

### 11.1 台湾ルート ── ドライヤー級を売りたいなら

1個1万円超の粗利を取りたいなら、商品単価を上げるしかありません。そして高単価品（ドライヤー・ダイソン、定価¥40,000〜50,000）は韓国では売れません。

**台湾は 110V / 60Hz、プラグはAタイプ。** 日本の100V機器は電圧差10%以内でほぼそのまま動きます。韓国で構造的に不可能だった商品群が、台湾では成立する可能性があります。

- 定価¥45,000の商品 → 粗利 ≒ 0.32 × 45,000 − 1,350 = **約¥13,000／個**
- モール：Shopee台湾、momo、PChome
- 要確認：台湾のBSMI検査（電気製品）、免税枠（NT$2,000 ≒ ¥9,500 と低く、課税前提になる）、年間輸入回数制限

**韓国×カラット系（薄利高回転）と台湾×ドライヤー（厚利低回転）は、資金効率の性格が逆です。** 両方を同時に立ち上げるべきではありません。どちらを先にやるかは、卸契約でどの商品が扱えるか次第です。

### 11.2 そもそも日本国内で売らない理由の説明

**出資者から必ず聞かれます。** 掛け率51%で仕入れられるなら、国内で定価近くで売れば1個¥11,662の値入れが取れ、国際送料も為替も関税も90日の入金待ちもありません。**なぜわざわざ韓国なのか。**

答えとして成立するのは次のいずれかです。事前に決めておいてください。

1. **卸契約で国内販売が制限されている**（越境なら可）── 最も説得力がある
2. 日本国内はAmazon・楽天で価格競争が激しく、実勢が定価を大きく下回る
3. 国内は既存販路との競合（チャネルコンフリクト）を避ける必要がある
4. 韓国のほうが単純に需要が大きく、数量が出る

**1 が該当するなら、それ自体が「なぜあなたにしかできないか」の説明になります。** 逆に該当しない場合、韓国に行く合理性を別途組み立てる必要があります。
