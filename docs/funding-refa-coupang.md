# 越境EC（ReFa / Dyson / Brighte）× 韓国Coupang ── 事業計画と資金の考え方

> **rev.5（2026-09-12）**：仕入をクレジットカード決済で行う前提を反映。
> **結論：仕入資金の調達は不要です。そして代わりに「カード与信枠」が事業規模の上限になります。**
>
> 前提の履歴 ── rev.1〜3 は「在庫を買い取る」前提で運転資金¥20,000,000の調達を組んでいた。rev.4 で無在庫・先払い不要の前提を反映。rev.5 で決済手段を確定。

---

## 0. 結論

### クレカ仕入でキャッシュフローは完全に成立します

| 注文タイミング | カード引落し | Coupang入金 | 差 |
|---|---:|---:|---:|
| 月初（9/1） | D+56 | D+50 | **入金が6日先行** |
| 月中（9/15） | D+42 | D+36 | **入金が6日先行** |
| 月末（9/30） | D+27 | D+21 | **入金が6日先行** |

**カードの締め日サイクル（月末締め・翌月27日払い）と、Coupangの精算サイクル（当月売上・翌月第15営業日）が、どちらも月末起点なので常に一定の6日差で噛み合います。** 月のどこで注文が入っても、**入金がカード引落しより先**に来ます。

つまり **仕入資金の立替はゼロ**。しかも金利ゼロで、ポイント還元がある分だけ**実質マイナス金利の調達**になっています。

### だから調達の論点はここに移ります

> **お金が足りないのではなく、カードの枠が足りない。**

仕入をカードで回す以上、**月間の仕入可能額 ＝ カード与信枠 ÷ 1.9** が事業規模の天井です（→ §2）。¥20,000,000を借りて仕入に使うより、**カード枠を¥20,000,000に上げるほうが、金利ゼロ・担保不要・希薄化なしで圧倒的に有利**です。

**この事業は、資金調達ではなくカード与信の積み上げでスケールします。**

## 1. クレカのフロートがCoupang精算と噛み合う

### 前提

| 項目 | 想定 |
|---|---|
| カード | 法人カード・**月末締め／翌月27日払い** |
| Coupang精算 | 当月売上 → **翌月第15営業日**（10月なら概ね10/21） |
| 発注から韓国着荷 | 6〜10日（受注→MTG発注→検品→国際発送→受領） |

### 流れ

```
D0     Coupangで受注
D0-2   MTGへカード決済で発注     ← 現金は出ない。カード債務が立つだけ
D2-5   自社着荷・検品・梱包
D5-10  韓国へ発送・受領
D21    Coupang入金               ← 現金が入る
D27    カード引落し              ← 現金が出る
```

**入金（D21）→ 引落し（D27）の順序が、月のどこで注文が入っても崩れません。**

### ⚠ ただし月末注文には注意

Coupangの売上計上が配送完了ベースの場合、**月末近くの注文は配送完了が翌月にずれ、入金が1ヶ月後ろに動きます。** その分だけ一時的に立替が発生します。

| 月間仕入額 | 翌月ずれ 10% | 16% | 25% |
|---:|---:|---:|---:|
| ¥1,578,947（枠¥3M） | ¥157,895 | ¥252,632 | ¥394,737 |
| ¥5,263,158（枠¥10M） | ¥526,316 | ¥842,105 | ¥1,315,789 |

**月間仕入の10〜25%程度の現金バッファを持っておけば吸収できます。** 大きな金額ではありません。

### ポイント還元が地味に効く

| 還元率 | 実質仕入率 | 年間3,700個・平均仕入¥15,000での額 |
|---:|---:|---:|
| 0.5% | 50.74%相当 | ¥277,500 |
| **1.0%** | **50.49%相当** | **¥555,000** |
| 1.5% | 50.23%相当 | ¥832,500 |

仕入率51%が実質50.5%になります。**掛け率交渉0.5ポイント分をタダで取っているのと同じ**です。

## 2. カード与信枠 ＝ 事業規模の上限

これが**新しい唯一のボトルネック**です。

### なぜ枠の1.9倍で割るのか

月末締め・翌月27日払いだと、毎月1日〜27日のあいだは **「先月分（まだ引き落とされていない）＋今月分（累積中）」** を同時に抱えます。したがって枠の実効利用倍率は約1.9ヶ月分。

> 締め日サイクルが短いカード（例：15日締め・翌月10日払い）なら倍率は1.5前後に下がり、**同じ枠でより多く回せます**。カードの選定で capacity が変わるので、ここは最適化の余地があります。

### 枠ごとの事業規模（平均仕入¥15,000／平均定価¥29,400／平均粗利¥9,000で試算）

| カード枠 | 月間仕入可能 | 月間件数 | 月商（定価） | 月間粗利 | **年間粗利** |
|---:|---:|---:|---:|---:|---:|
| ¥1,000,000 | ¥526,316 | 35件 | ¥1,031,579 | ¥315,789 | ¥3,789,474 |
| ¥3,000,000 | ¥1,578,947 | 105件 | ¥3,094,737 | ¥947,368 | ¥11,368,421 |
| ¥5,000,000 | ¥2,631,579 | 175件 | ¥5,157,895 | ¥1,578,947 | ¥18,947,368 |
| ¥10,000,000 | ¥5,263,158 | 351件 | ¥10,315,789 | ¥3,157,895 | ¥37,894,737 |
| ¥20,000,000 | ¥10,526,316 | 702件 | ¥20,631,579 | ¥6,315,789 | ¥75,789,474 |
| ¥30,000,000 | ¥15,789,474 | 1,053件 | ¥30,947,368 | ¥9,473,684 | ¥113,684,211 |

**枠と利益がきれいに線形です。** 出資者に見せるならこの表が一番わかりやすい ── ただし「だからお金をください」ではなく「だからカード枠を上げます」が正しい結論です。

### 枠を上げる手段（調達より先にこれ）

1. **利用実績を積む** ── カード会社の与信枠は、決済額と支払い実績で上がる。最初の3〜6ヶ月が効く
2. **一時増枠を使う** ── 多くの法人カードで、事前申請により一時的な増枠が可能
3. **一律の上限枠がないカード** ── AMEXビジネス等は固定枠を持たず、利用実績に応じて変動する
4. **複数枚を併用** ── 枠を分散して合計capacityを上げる
5. **締め日サイクルの短いカードに寄せる** ── 実効倍率が下がり、同じ枠で多く回せる

**これらを全部やって足りなくなったときに、初めて仕入資金の調達が意味を持ちます。**

## 4. ⚠ 唯一の実測データが、定価出品を否定している

| | 値 |
|---|---|
| リファカラットレイフェイス 定価 | ¥25,190 |
| **定価で出品した場合** | **₩239,305** |
| 韓国の直購実勢 | ₩134,410 〜 ₩183,000 |
| 実勢の上限に対して | **+31%** |
| 損益分岐（定価の63.3%） | ₩151,423 |

**定価出品では市場より31%高く、売れません。** ただし損益分岐は ₩151,423 なので、₩165,000〜183,000 のレンジで出せば粗利は残ります。

> **定価は出発点であって、着地点ではない。SKUごとに韓国の相場を測り、定価の65〜100%の間のどこで出すかを決める。それが粗利を決める。**

ファインバブル・日傘・バイタルウェア・OnTrac の韓国相場は**まだ測っていません**。§3の粗利はすべて「定価で売れたら」の数字です。**ここが本資料に残る唯一にして最大の未検証項目です。**

## 5. 無在庫の生命線 ── 欠品キャンセル

Coupang Global は出荷リードタイムを出品時に自己申告でき、さらに**6営業日のバッファを自動で上乗せ**します。グローバルセラーについては出荷の遅れ自体はセラースコアに影響しません。受注発注モデルは構造的に許容されています。

**ただしCoupangは「品切れによる注文キャンセル」を、誰がキャンセルしたかに関わらずセラースコアに反映します。** スコアが下がれば出品停止、さらにアカウント停止まで行きます。

| 在庫状況 | SKU数 | 比率 |
|---|---:|---:|
| 在庫あり | 1,426 | 92.5% |
| 在庫なし | 71 | 4.6% |
| 不明 | 45 | 2.9% |
| **在庫なし＋不明** | **116** | **7.5%** |

**2026-08-26時点で、カタログの7.5%が引けません。** HP掲載商品を全部出品して在庫同期をしなければ、受注のうち相当数が欠品キャンセルになります。

> **これが Compass（在庫同期・自動出品システム）の存在理由そのものです。** 無在庫モデルにおいて在庫同期は「あると便利な機能」ではなく「事業が死なないための必須インフラ」。

その他の運用上の論点：

- MTG ONLINESHOP は国内発送のみと思われるため、**日本の自社住所を経由する二段階**になる前提で設計する
- 無在庫でも1件ごとに検品・梱包・発送の作業が発生する。**ボトルネックは資金ではなく、カード枠と作業量**

## 7. 必要な資金と、その性格

### 仕入資金：不要

カードで回る限りゼロ。必要なのは月末ズレ吸収用のバッファ（月間仕入の10〜25%）だけです。

### 立ち上げ・オペレーション資金

| 項目 | 金額 | 内容 |
|---|---:|---|
| 出品オペレーション | ¥1,200,000 | SKUの撮影・韓国語化・カテゴリマッピング・登録 |
| **在庫同期システム（Compass）** | ¥1,500,000 | **無在庫モデルの生命線** |
| 韓国語CS・受注処理 | ¥900,000 | 立ち上げ6ヶ月分 |
| 広告・初期露出 | ¥600,000 | |
| 月末ズレ・返品・為替のバッファ | ¥800,000 | |
| **計** | **¥5,000,000** | |

### 調達手段

| | 評価 |
|---|---|
| **カード枠の引き上げ（最優先）** | **金利ゼロ・担保不要・希薄化なし・ポイント還元つき。** 仕入資金についてはこれが最適解 |
| 借入 | 在庫がないので担保に出すものがない。カードより条件が悪い |
| **Compass に対するエクイティ** | 立ち上げ費用¥5,000,000とシステム開発について。無在庫モデルは「在庫同期が必須インフラ」であることを自明にするので、このストーリーは強い |

**「運転資金を貸してください」ではなく、「カード枠で回せるところまで自走します。出資はCompassに対してお願いしたい」が、この前提での正しい言い方です。**

## 9. クレカ仕入に固有のリスク

| リスク | 影響 | 対策 |
|---|---|---|
| **同一加盟店への高額反復決済が不正検知で止まる** | 高 | **事前にカード会社へ事業利用と想定月額を申告**しておく。止まると仕入が即停止する |
| **MTGがカード決済を継続して受けるか**（「一旦」が引っかかる） | 高 | 高額反復になると振込に切り替えを求められる可能性。**その場合の支払条件を先に握っておく** |
| カード枠が事業の天井になる | 中 | §2の手段で積み上げる。枠の使用率をKPIとして毎月見る |
| 返品時の現金流出 | 中 | カード債務は確定済み。返品分は先に払って後で回収。引当3%をバッファに |
| 月末注文の売上繰越 | 低 | 月間仕入の10〜25%のバッファで吸収 |
| 為替（Coupang入金はUSD、カード支払いはJPY） | 中 | 円高で入金が目減りする。価格改定を月次サイクルに |
| カード与信が個人保証に紐づく | 中 | 実質的に個人リスクを負う点は認識しておく |

## 10. 実行前に潰すこと（優先順）

1. **カードの締め日・支払日・与信枠・一時増枠の可否**を確定 ── §2の全体がここに乗っている
2. **カード会社へ事業利用の事前申告**（不正検知で止まると仕入が即停止）
3. **MTGがカード決済を継続して受けるか**、および「一旦」の先の支払条件
4. **掛け率が51%か50%か**（スプレッドシートの列見出しは「定価の50%」）
5. **卸契約に越境販売・海外転売・再販地域の制限条項がないか**
6. **MTGが在庫APIまたは在庫データを提供できるか** ── 無在庫モデルの生命線
7. 柱となるSKUの韓国直購実勢価格を実測し、「定価の65〜100%」のどこに着地するかを決める
8. MTG ONLINESHOP が法人向けに**直接韓国へ発送できるか**
9. Dyson OnTrac の充電器が100-240V対応かを現物確認／ファインバブルの韓国給水ホース規格（G1/2）互換性
10. 会員限定14／定期購入45／予約48 SKU の転売可否／輸出免税による消費税還付の可否／韓国の関税率（HSコード別）
