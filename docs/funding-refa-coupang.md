## 0. 結論を先に

**この資金使途の立て方（在庫を先に買う運転資金）は正しい。ただし「1個あたり利益10,000〜15,000円」という言い方は、出資者に見せた瞬間に崩れます。**

- その利益額は「**日本の定価 − 仕入値**」です。「**韓国の実売価格 − 全コスト**」ではありません。
- 韓国でのリファ カラット系の実売は **₩101,300〜₩183,000** で観測されます（§3）。日本定価を超える価格では売れません。
- 1個1万円の利益を出すには韓国で **₩276,000** 前後で売る必要があり、これは日本の定価（¥26,180 税込）より高い。成立しません。
- **実際に狙える粗利は1個あたり ¥1,700〜¥3,600（粗利率 10〜18%）。**

これは事業を否定する数字ではありません。**語り方を変えるべきという数字**です。

> 「1個1.5万円儲かります」→ 出資者は3分で検算して、話が終わります。
> 「粗利率は12%しかありません。ただし資本が**年4回転**するので、投下資本に対しては**年50〜100%**回ります。だから資本の量がそのまま利益の量になる。だから資金が要る」
> → こちらは検算に耐えます。そして**出資額と利益が線形につながる**ので、追加出資の理屈も自動的に立ちます。

薄利高回転ビジネスは、**薄利であること自体が資金需要の証明**になります。ここが今回のストーリーの芯です。

## 2. なぜ「リファ カラット系」に絞るのか（ダイソン・ブライトを外す理由）

ここは投資家に対して一番効く論点です。商品選定が**思いつきではなく構造的な理由**で決まっていることを示せます。

### 電気製品は韓国向けに構造的に向かない

| | 日本仕様 | 韓国 | 帰結 |
|---|---|---|---|
| 電源電圧 | 100V | **220V / 60Hz** | 日本仕様のドライヤー・ヘアアイロンは**そのまま使えない** |
| プラグ形状 | Aタイプ | **C / Fタイプ** | 変換＋変圧器が必須 |

ダイソンのドライヤー、リファ ビューテック ドライヤー／ストレートアイロンは、いずれも日本仕様が100V。韓国の購入者が変圧器なしで使うと動かないか故障します。**返品率とレビュー評価が壊れ、Coupangのアカウント健全性スコアに直撃します。** ここは規制の問題ではなく物理の問題なので、書類でも交渉でも回避できません。

### 一方、リファ カラット系は非電気製品

- 電源なし・電池なし。**ソーラーパネルでマイクロカレントを発生させる構造**
- IPX7防水
- → 電気用品安全法（韓国KC）・電波法の対象外。変圧器不要。故障モードがほぼない

なお韓国の海外直購（해외직구）では、電気用品であっても**個人の自家使用目的なら「モデル別1個」までKC認証が免除**され、別途申請も不要です。つまり**規制上は電気製品も通ります**。しかし上記の通り、通関を通っても**製品が動かない**のでは意味がありません。この2つを混同しないことが重要です。

> リポジトリ内の `docs/onboarding-coupang-global.md` §7 は「電気電子製品はKC対象なので初期は避ける」と書いていますが、Global Marketplace（해외직구）ルートでは自家使用免除が効くため、厳密にはKCが障壁ではありません。**実際の障壁は電圧です。** 加盟店向け資料としてこの点は補正したほうが正確です。

### 価格帯の副次的メリット：$150 免税枠に収まる

韓国の海外直購は、課税価格 **$150以下**なら関税・付加価値税が免除されます（目録通関）。1ドル未満でも超えると全額に課税されます。

- リファ カラット ₩185,000 ≒ **$132** → **免税圏内**
- ダイソン ドライヤー ₩500,000超 → 常に関税8% + VAT10%が購入者負担

つまりリファ カラット系は、**購入者が追加の税金を払わずに買える価格帯**にちょうど収まります。これは高単価品に対する明確な優位です。**販売価格の上限は ₩210,000（=$150）** と設計上ロックすべきです。

> 注：目録通関と一般輸入申告で「海外配送料を課税価格に算入するか」の扱いが異なります。実運用前に関税庁の予想税額照会で要確認。

## 3. 韓国市場の実勢価格（ここが最重要）

「리파 캐럿 레이 페이스」の韓国流通価格として観測されるもの：

| 価格（KRW） | 円換算（@9.5） | 性格 |
|---:|---:|---|
| ₩74,300 | ¥7,821 | 真贋要確認レンジ |
| ₩101,300 | ¥10,663 | 直購・並行輸入 |
| ₩134,410 | ¥14,148 | 直購・並行輸入 |
| ₩169,400 | ¥17,832 | 国内モール（新世界モール等） |
| ₩183,000 | ¥19,263 | 正規流通の実勢 |

**わかること：**

1. 韓国市場は**すでに並行輸入と直購で埋まっている**。空いている市場ではありません。
2. 下限価格帯（₩101,300、₩74,300）は、**こちらの仕入原価 ¥12,138（≒₩115,300）を下回っています**。この層とは価格で戦えません。
3. MTGの**韓国唯一の公式販売代理店（KOSHOP）が存在**します。上位価格帯は正規代理店が押さえています。
4. MTG自身が**偽造品への注意喚起**を出しており、KREAMは「偽物なら購入価格の3倍補償」を打ち出しています。**韓国市場では「正規品であること」に値段がついている。**

→ **戦う場所は価格の最下層ではなく、「日本の正規卸ルートのインボイスを提示できる中〜上位価格帯」です。** そしてこれは、あなたの51%卸口座が**そのまま差別化資産になる**ということでもあります。

## 5. なぜ資金が要るのか ── CCC（現金が戻ってくるまでの日数）

**これが資金使途の全部です。** 1枚で説明できます。

```
D0     仕入代金を支払う（前払い）           ← ここで現金が出ていく
D0-14  メーカー/卸からの入荷リードタイム
D14-21 検品・撮影・韓国語化・Coupang登録
D21-51 在庫滞留（平均30日で販売）
D51    販売成立
D51-56 韓国へ国際配送・受領
D56-90 Coupang精算（当月売上 → 翌月第15営業日に入金）
D90    入金                                ← ここで現金が戻る
```

**仕入から入金まで、約90日。** さらにCoupangは月次精算・月100万KRW未満は翌月繰越なので、立ち上がり期はさらに伸びます。

**つまり：**

- 月に1,000個売る体制を作るには、**常時3ヶ月分＝3,000個分の仕入代金が寝ている**必要がある
- 3,000個 × ¥12,138 = **¥36,414,000**
- これは売上が増えるほど**増える**（成長するほど資金が足りなくなる典型的な運転資金型ビジネス）

**在庫は実物資産として残ります。** 最悪の場合でも日本国内で処分売りして原価の相当部分を回収できる。出資者から見て、これは損失が青天井にならないということです。ここは明示すべき安心材料です。

## 6. 調達の設計

### 6.1 これは本来「借入」の案件です（重要）

先に正直に言っておくと、**資金使途が運転資金の立替だけなら、エクイティ（出資）は調達手段として不利**です。

- 出資者から見て：粗利率12%の物販に株で入る理由がない。年利10〜15%で貸したほうがリスク調整後リターンが良い
- あなたから見て：株を渡すと、**このビジネスが将来生む利益を永久に分配し続ける**ことになる。90日の立替に対する対価としては高すぎる

投資家に「なぜ銀行や日本政策金融公庫ではなく、うちなんですか？」と必ず聞かれます。ここに答えを用意していないと、ストーリーの整合性が崩れます。

**用意すべき答えは2つのどちらかです：**

| | ストーリー |
|---|---|
| **A. 借入で取る** | 「銀行は実績のない越境ECに在庫担保で貸さない。最初の1年の実績を作るための**つなぎ**として借りたい。実績ができたら銀行に借り換える」<br>→ 誠実で、金額も条件も小さくまとまる。**この資金使途だけならこちらを推奨** |
| **B. 出資で取る** | 「リファの物販は**単体で儲けるためにやるのではない**。Coupang越境ECの運用フローを自社で回して実証し、それを Compass（システム＋フランチャイズ）として他の事業者に売る。**物販は実証エンジンで、売り物はその先のシステム**」<br>→ エクイティを正当化できる唯一の筋。ただし Compass の話とセットでしか成立しない |

「↑の話ではなく資金使途だけ」に絞るなら **A**。出資を取りたいなら **B** に戻る必要があります。ここは二者択一です。

## 8. リスクと対策

| リスク | 影響度 | 対策 |
|---|---|---|
| **卸契約に越境転売の禁止条項がある** | **致命的** | 資金実行の前提条件（CP）として書面確認。ここが黒なら計画ごと中止 |
| MTG・韓国正規代理店からの権利申立て | 高 | 正規インボイスを全ロット保管し、Coupangへ即時提出できる体制。ブランド側への事前通知も検討 |
| Coupangアカウント停止 | 高 | 規約遵守、返品率・レビュー監視、Qoo10等への分散 |
| 韓国実勢価格の下落 | 高 | 損益分岐 ₩146,000 を下回ったら**仕入停止**をルール化 |
| 為替（円高） | 中 | KRW建て売上のUSD受取、価格改定を月次サイクルに |
| 在庫滞留 | 中 | 初回小ロット、回転日数で仕入判断、国内転売で原価回収 |
| Coupang入金サイトの長さ | 中 | これ自体が資金使途。2ヶ月分のバッファを予備費に |
| 偽造品との価格競争 | 中 | 正規ルート証明を前面に。最下層価格帯とは戦わない |

**Coupangは知的財産権ポリシーとして、出品者に「仕入インボイス」または「権利者の許諾」の提出を求めることができます。** 51%の正規卸ルートでインボイスが出せることは、この局面で**リスクではなく武器**になります。ストーリー上、ここは前面に出すべきです。

## 9. 実行前に潰すべき確認事項

数字を作り込む前に、これらを先に潰してください。ここが割れると資料ごと無駄になります。

1. **卸契約書に越境販売・海外転売・再販地域の制限条項がないか**（最優先・これが全ての前提）
2. 掛け率51%が適用される最低発注数量と、その支払条件（前払い／掛け／サイト日数）
3. リファ カラット系の**現在の日本定価**（SKU別に確定させる。CARAT / CARAT RAY / CARAT RAY FACE / S CARAT RAY）
4. 韓国Coupang上での同一SKUの**実売価格・出品者数・アイテムウィナー**（1週間の実測）
5. 輸出免税による**仕入消費税の還付が適用できるか**（税理士確認。1個あたり¥1,200相当の差）
6. 韓国の関税率（HSコード分類）と、RCEP原産地証明による軽減の可否
7. 国際送料の実見積（DHL / FedEx / EMS / 佐川グローバル、混載時の1個あたり単価）
8. マイクロカレント機器が韓国で**医療機器に該当しないこと**の確認（美容機器としての訴求に限定）
9. 為替レートの実勢値への更新（本資料は ¥1=₩9.5 の仮置き）
