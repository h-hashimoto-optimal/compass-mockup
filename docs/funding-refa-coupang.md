# 越境EC（ReFa / Dyson / Brighte）× 韓国Coupang ── 事業計画と資金の考え方

> **rev.6（2026-09-12）**：アイテムウィナー（아이템위너）の獲得可能性を商品別に分析し、モデル定義を「**無在庫（受注発注）＋仕入は現金**」に変更した。
>
> **先にお断り**：Coupangのサイトはこの環境からアクセスできず、**SKUごとの現在のアイテムウィナーを直接は確認できていません**。代わりに ①選定基準の調査 ②勝敗を決める判定式の導出 ③韓国の正規価格が判明した3商品への適用 を行っています。生データの取り方は §8 に手順として書きました。

---

## 0. 結論

### アイテムウィナーは「価格でしか」取れません

Coupangは同じ商品を複数のセラーが出品すると**1つの商品ページに統合し、勝った1社だけがカートを獲得**します。選定基準は6つ。この事業モデルを当てはめると：

| 選定基準 | この事業モデルの評価 |
|---|---|
| 販売価格 | **○ 51%仕入で35〜40%の値下げ余地。唯一戦える軸** |
| 単位価格（2024/7追加） | ○ 同上 |
| 送料 | △ 国際送料を売価に含めるか買い手負担かで変わる |
| 在庫数 | **✕ 無在庫なので潤沢な在庫を申告できない** |
| 出荷所要日数 | **✕ 日本発 6〜10日 vs 韓国国内 1〜2日** |
| セラースコア | **✕ 新規は実績ゼロ。欠品キャンセルでさらに下がる** |

**6基準のうち3つが構造的に不利です。価格で圧勝する以外に勝ち筋はありません。**

### 勝敗はこの1つの比率で決まります

```
K ＝ 韓国の正規販売価格 ÷（日本定価 × 為替）

K > 1.18  → 免税枠外でも、日本の定価のまま出品して価格優位（◎）
K > 1.00  → 免税枠内（定価¥22,105以下）なら、定価のまま価格優位（◎）
K < 0.733 → 損益分岐まで下げても正規に勝てない（✕ 撤退）
その間    → 値下げすれば戦えるが、粗利は削られる（△）
```

### 韓国価格が判明した3商品への適用

| 商品 | 日本定価 | 韓国正規 | **K** | 判定 | 定価出品時の買い手実負担 |
|---|---:|---:|---:|:-:|---:|
| **Dyson OnTrac ヘッドホン** | ¥54,780 | ₩699,000 | **1.343** | **◎ 定価のまま勝てる** | 正規比 **−12%**／粗利 **¥18,895** |
| リファ ファインバブル ピュア | ¥35,940 | ₩330,000 | **0.967** | △ 値下げ要 | 正規比 **+22%** |
| リファ カラットレイフェイス | ¥25,190 | ₩207,400 | **0.867** | ✕ ほぼ無理 | 正規比 **+36%** |

**ダイソンは韓国で日本より34%高く売られているので、日本の定価のまま出しても買い手の実負担が正規より12%安くなります。** 一方リファは韓国の正規価格が日本の定価とほぼ同水準（K≒0.97）なので、関税+VAT 18%の分だけ最初から不利です。

### だから本命は「競合のいないSKU」です

Coupangのカタログは、**商品名・代表画像・詳細説明がほぼ同じ場合に自動でマッチング**されて1ページに統合されます。逆に言えば、**韓国で売られていないSKUは新しい商品ページになり、単独出品＝自動的にアイテムウィナー**です。

韓国の公式モール（refa.kr）が扱っているSKUは日本の1,542 SKUのごく一部。**無在庫ならロングテールSKUを大量に出すコストがほぼゼロ**です。競合SKUで殴り合うのではなく、**空いている棚を取りにいくのが正解**です（→ §3）。

## 1. アイテムウィナーの仕組み

### 統合のされ方

Coupangは同一商品と判断した出品を1つのアイテムページに統合します。判断基準は：

- 商品名がほぼ同じ
- 代表画像がほぼ同じ
- 詳細説明がほぼ同じ
- その他、同一商品と判断できる根拠が明確な場合

**統合されると、勝った1社だけがカートボタンを獲得**し、他社は「他の販売者を見る」の中に隠れます。売上はほぼ全部ウィナーが取ります。

### 選定基準（Coupang公表）

| 基準 | 有利な方向 |
|---|---|
| 販売価格 | 低いほど有利 |
| **単位価格** | 低いほど有利（2024年7月28日から追加） |
| 送料 | 低いほど有利 |
| 在庫状況 | 潤沢なほど有利 |
| 出荷所要期間 | 短いほど有利 |
| セラースコア | 高いほど有利 |

### この事業モデルの構造的な立ち位置

**不利な3つは、努力では埋まりません。**

- **出荷所要日数**：受注 → MTG発注 → 自社着荷 → 検品 → 国際発送 → 韓国着荷で6〜10日。韓国国内セラーは1〜2日。ロケット配送なら翌日
- **在庫数**：無在庫なので「在庫100個」とは申告できない（申告して欠品するとセラースコアに直撃する）
- **セラースコア**：新規は実績ゼロから。欠品キャンセルが出れば下がる

**有利にできるのは価格だけ。そして51%仕入は、その価格競争のための武器としては強力です**（損益分岐は定価の60〜65%＝35〜40%引きまで耐える）。

## 2. 勝敗を決める K 比率

### 導出

買い手が実際に払う額で比較しないと意味がありません。海外直購では **$150（≒₩210,000 ≒ 日本定価¥22,105）を超えると関税8%＋VAT10%が買い手負担**になります。

```
定価出品時の買い手実負担 ＝ 日本定価 × 為替 × 1.18（免税枠外）／ × 1.00（免税枠内）
これが韓国正規価格を下回る条件 ＝ K > 1.18（枠外）／ K > 1.00（枠内）
```

### 撤退ライン

損益分岐は定価の約62%。そのときの買い手実負担は `日本定価 × 6.96`。
**韓国正規価格がこれを下回る（K < 0.733）なら、どこまで値下げしても正規に勝てません。撤退です。**

### 3商品の詳細

**■ Dyson OnTrac ヘッドホン ── K 1.343 ◎**

| | 値 |
|---|---|
| 日本定価 ¥54,780 → 出品 | ₩520,410 |
| 買い手実負担（関税+VAT 18%） | ₩614,084 |
| 韓国正規 | ₩699,000 |
| **正規比** | **−12%** |
| 粗利（定価出品） | **¥18,895**（34.5%） |
| 損益分岐 | ₩320,696（実負担₩378,421＝正規比−46%） |

**値下げ余地が正規比−46%まであります。** 価格でアイテムウィナーを取りにいける唯一の高単価商品です。ただし出荷日数・在庫数・セラースコアの不利は残るので、**正規比−20〜25%あたり（₩450,000前後）まで攻めて確実に取る**のが現実的。そのときの粗利は **¥12,457（26.3%）**。

**■ リファ ファインバブル ピュア ── K 0.967 △**

定価出品では買い手実負担が正規比**+22%**。勝てません。
実負担を正規比−10%（₩297,000）にするには出品価格 ₩251,695 まで下げる必要があり、そのときの粗利は **¥3,653（13.8%）**。成立はしますが薄い。

**■ リファ カラットレイフェイス ── K 0.867 ✕**

定価出品では正規比**+36%**。
実負担を正規比−10%にすると出品価格 ₩158,186、粗利 **¥623（3.7%）**。事実上、商売になりません。さらに韓国の直購市場では ₩134,410 の出品が存在し、これは損益分岐 ₩151,423 を下回っています。**このSKUは見送るべきです。**

### わかったこと

**ブランドによってKの水準が構造的に違います。**

- **Dyson**：韓国の正規価格が日本より3割以上高い → **越境で勝てる**
- **ReFa**：韓国の正規価格が日本とほぼ同水準（韓国法人が日本価格に合わせている） → **関税分だけ最初から不利**

→ **同じ51%仕入でも、ダイソンとリファでは越境ECの成立条件が全く違います。** ダイソンは電圧の壁で大半が落ちますが、落ちなかったOnTracは非常に良い商材です。

## 3. 本命はロングテール単独出品

### 競合SKUで殴り合わない

カタログマッチングは商品名・画像・詳細説明の類似で働きます。**韓国で売られていないSKUは、新しい商品ページとして登録され、単独出品＝自動的にアイテムウィナー**になります。

- 韓国公式モール refa.kr が扱うのは日本の1,542 SKUのごく一部（ビューティシャワー等の主力のみ）
- 日本側には **バイタルウェア226 / リネン176 / シルク57 / 日傘21 / リファハート133** など、韓国未展開のカテゴリが厚い
- **無在庫ならロングテールSKUの出品コストはほぼゼロ**（撮影・韓国語化の作業だけ）

### 出品の優先順位

| 優先 | 条件 | 狙い |
|---|---|---|
| **1** | 韓国に競合出品なし × 免税枠内（定価≤¥22,105） | **単独ウィナー＋買い手に関税なし。最強の組み合わせ** |
| 2 | 韓国に競合出品なし × 免税枠外 | 単独ウィナー。関税分の割高は許容される（比較対象がない） |
| 3 | K > 1.18 の競合SKU | 定価のまま価格優位（＝Dyson OnTrac） |
| 4 | 0.733 < K < 1.18 の競合SKU | 値下げして戦う。粗利は削られる |
| **除外** | K < 0.733 | どう下げても勝てない |

**「まず1と2を全部出す」が無在庫モデルの正しい初手です。**

### ⚠ ただし単独出品には別のリスク

- 後から他セラーが同じSKUを出すと統合され、価格競争が始まる
- **他セラーがあなたの商品画像・説明文を流用して同じページに乗ってくる**ことがある（Coupangのアイテムウィナー制度で知られた論点）
- 需要があるかどうかは未知。売れないSKUを大量に出しても在庫リスクはないが、**出品作業のコストは戻ってこない**

## 4. モデル定義の変更 ── 無在庫だが、仕入は現金

**在庫は持たない（受注してから発注する）。ただし仕入代金は現金で先に払う。**

### 資金拘束の計算

```
受注日 d に現金で仕入 → その月の売上は翌月第15営業日（≒21日）に入金
拘束日数 ＝ (30 − d) + 21 ＝ 51 − d
d = 1..30 の平均 ＝ 35.5日

定常状態の所要運転資金 ＝ 月間仕入額 × 35.5/30 ＝ 月間仕入 × 1.18
```

在庫を持つモデル（rev.1〜3）の90日拘束と比べると**約6割**です。在庫滞留の30日と入荷リードタイムが消えるため。

**これが資金使途の説明になります。** 在庫を買うためではなく、**受注してから入金までの35日を埋めるため**。在庫リスクはゼロで、資金は必ず35日で戻ってくる ── 出資者にとってこれは在庫買取モデルよりはるかに説明しやすい構造です。

### ⚠ 年間粗利は「粗利/個」次第で大きく振れます

§2で見た通り、実現粗利はSKUによって ¥623 〜 ¥18,895 まで開きます。月300件での年間粗利は：

| 粗利/個の前提 | 年間粗利（月300件） |
|---:|---:|
| ¥3,000（リファ競合SKU） | ¥10,800,000 |
| ¥6,000 | ¥21,600,000 |
| ¥9,000 | ¥32,400,000 |
| ¥18,895（OnTrac定価出品） | ¥68,022,000 |

**平均粗利が決まるのはSKUミックスが決まってからです。** 出資者に単一の数字を出すのは危険で、「K比率で選別したSKUで構成すると粗利/個は◯◯になる」という形にすべきです。

| 値入れ（定価−仕入）の帯 | SKU数 | 韓国で売れない割合 |

| ¥20,000以上 | 128 | **63.3%** |

値入れが大きいのはドライヤー・ヘアアイロン・掃除機・空気清浄機・照明 ＝ すべて100V AC直結。韓国は220Vで動きません。

**スクリーニング：1,542 → 1,091 SKU**（100V・大型 −266／在庫なし・不明 −81／会員限定・定期・予約 −104）。

### 無在庫の生命線 ── 欠品キャンセル

Coupangは**品切れによるキャンセルを、誰がキャンセルしたかに関わらずセラースコアに反映**します。スコアが下がれば出品停止、さらにアカウント停止。

シートの実データでは **在庫なし71 ＋ 不明45 ＝ 116 SKU（7.5%）** が引けない状態。**在庫同期（Compass）は必須インフラ**です。しかもセラースコアはアイテムウィナーの選定基準でもあるので、**欠品はスコアを下げ、スコアが下がればウィナーも失う**という二重の打撃になります。

## 7. 調達の設計

### 資金使途

| 項目 | 金額 | 性格 |
|---|---:|---|
| **運転資金（受注→入金の35日を埋める）** | **月間仕入 × 1.18 × 1.2** | 在庫リスクなし。35日で回収 |
| 出品オペレーション | ¥1,200,000 | 撮影・韓国語化・カテゴリマッピング・登録 |
| 在庫同期システム（Compass） | ¥1,500,000 | 無在庫モデルの生命線 |
| 韓国語CS・受注処理 | ¥900,000 | 立ち上げ6ヶ月分 |
| 広告・初期露出 | ¥600,000 | |

**月300件を目指すなら：運転資金 ¥6,372,000 ＋ 立ち上げ ¥4,200,000 ＝ 約¥10,500,000。**

### 調達手段

| 手段 | 評価 |
|---|---|
| **貸付型** | 運転資金は**35日で必ず回収される短期資金**。在庫リスクがないので貸し手から見て安全。年利10〜12%、売掛（Coupang入金）を裏付けに。**運転資金部分はこれが最適** |
| クレジットカード | 使えるなら実質的な無利子調達になるが、「一旦」という条件と不正検知リスクがある。**併用して枠を温存するのが現実的** |
| Compass へのエクイティ | 立ち上げ費用¥4,200,000とシステム開発について |

**「在庫を買う金」ではなく「受注済みの売掛を35日つなぐ金」です。** これは説明が通ります。

## 8. アイテムウィナーの実測手順

私はCoupangに直接アクセスできなかったので、**以下は実際に手を動かして取ってください。** 1SKUあたり5分、50 SKUで半日の作業です。

### 手順

1. Coupangアプリ／Webで対象SKUの韓国語商品名で検索
2. **既存の商品ページがあるか**を確認
   - **なければ** → 単独出品可能。優先度1または2（→ §3）
   - **あれば** → 3へ
3. 商品ページを開き、次を記録する
   - 現在のアイテムウィナーの**販売価格・送料・出荷所要日数・販売者名**
   - 「他の販売者を見る」を開いて**競合セラー数と各社の価格**
   - **ロケット配送／ロケット直구バッジの有無**（あれば配送速度で勝てないので価格差をさらに広げる必要あり）
4. **韓国正規価格**（refa.kr / dyson.co.kr / 公式代理店）を記録
5. **K ＝ 韓国正規価格 ÷（日本定価 × 為替）** を計算して §2 の判定に当てはめる
6. 競合がいる場合は、**ウィナーの価格を下回れるか**を損益分岐（定価の60〜65%）と照らす

### 記録シートの列
