## 0. 結論

### データで裏が取れたこと

**「1個あたり10,000〜15,000円」は正しい数字でした。** 前回まで「その金額は出ない」と書いたのは誤りで、訂正します。卸値が**定価（税込）の50%**で、定価¥20,000〜30,000のSKUが大量にあるので、値入れ1万〜1.5万円は普通に成立します。それどころか値入れ¥20,000超のSKUが128件、¥30,000超が38件あります。

### ただしデータが同時に突きつけたこと

| 値入れ（定価−卸値）の帯 | SKU数 | **韓国で売れないSKUの割合** |
|---|---:|---:|
| 〜¥5,000 | 824件 | **1.7%** |
| ¥5,000〜10,000 | 255件 | **9.0%** |
| ¥10,000〜20,000 | 335件 | **44.2%** |
| ¥20,000以上 | 128件 | **63.3%** |
| （うち¥30,000以上） | 38件 | **73.7%** |

**値入れが大きいSKUほど、韓国で売れなくなります。きれいな単調増加です。**

理由は単純で、このカタログで値入れが大きいのは**ドライヤー・ヘアアイロン・掃除機・空気清浄機・照明**、つまり **100V AC直結の電気製品**だからです。韓国は220V。動きません。

### だから論点はこうなる

> **「1個1.5万円の商品を仕入れられること」は証明済み。**
> **「その1.5万円の商品を韓国で売れること」が証明されていない。**

出資者に見せるべきはこの1行です。そして本資料は、1,542 SKUから**韓国で売れて値入れも大きい1,091 SKU**を機械的に抽出し、そのうち3つの柱に絞り込むところまでを示します。

## 2. 「粗利」列は値入れであって、手元に残る額ではない

スプレッドシートの `粗利(定価-卸値)` は **日本の定価で、日本国内で、コストゼロで売れた場合**の数字です。越境ECで実際に残る額は、そこから次が引かれます。

| 引かれるもの | 率／額 |
|---|---|
| 韓国売値と日本定価の差 | 実測が必要（→ §6） |
| Coupang 販売手数料 | 8%（カテゴリ別4〜11%） |
| 決済・為替スプレッド・送金 | 1.5% |
| 返品・不良・値引引当 | 3.0% |
| 国際送料（国際eパケット・個口） | ¥1,100〜1,600／個 |

**変動費 12.5% ＋ 固定費（卸値＋送料）** が実務式です。本資料の実現粗利はすべてこの式で計算しています。

> Coupang Global Marketplace は**注文ごとに日本から韓国の購入者へ個口発送**します。コンテナ混載は効きません。送料は1個あたりコストとしてそのまま乗ります。

## 6. ⚠ 最大の弱点 ── 韓国売値を1つしか実測できていない

**上の表の韓国売値は、ファインバブル・OnTrac・アパレルについては私の仮置きです。** 実測できたのはカラット系1品だけで、そしてその1品の結果が良くありません。

| SKU | 卸値 | 韓国実測売値 | 実現粗利 | 粗利率 |
|---|---:|---:|---:|---:|
| リファカラットレイフェイス | ¥12,595 | ₩183,000（上限） | ¥3,160 | 16.4% |
| リファカラットレイフェイス | ¥12,595 | ₩165,000 | **¥1,502** | 8.7% |
| （参考）損益分岐 | | **₩148,689** | ¥0 | 0% |

韓国の直購市場ではカラットレイフェイスが **₩134,410** で出品されており、**これは損益分岐 ₩148,689 を下回っています。**

**つまり、実測できた唯一のSKUは「韓国の直購相場が日本の卸値まで崩れている」ことを示しています。** ファインバブルやOnTracで同じことが起きていない保証はどこにもありません。

§5の試算は「韓国売値が日本定価の85〜95%で立つ」という仮定の上にあります。**この仮定が本資料の全体を支えており、90日の実測でしか検証できません。** 出資者にはこの一点を隠さず提示すべきです。むしろ「ここだけが未検証で、それを検証するための資金です」と言い切るほうが通ります。

## 7. なぜ資金が要るのか ── CCC 90日（rev.1から不変）

```
D0     仕入代金を支払う（前払い）        ← 現金が出ていく
D0-14  卸からの入荷リードタイム
D14-21 検品・撮影・韓国語化・出品登録
D21-51 在庫滞留（平均30日で販売）
D51    販売成立
D51-56 韓国へ国際配送・受領
D56-90 Coupang精算（当月売上 → 翌月第15営業日）
D90    入金                          ← 現金が戻る
```

**仕入から入金まで約90日。** 月1,000個の体制には、常時3ヶ月分の仕入代金が寝ます。平均卸値¥17,202なら **3,000個 × ¥17,202 = ¥51,606,000**。

成長するほど資金が足りなくなる典型的な運転資金型ビジネスです。ただし資金は在庫という実物資産に変わるので、最悪でも国内処分で原価の相当部分を回収でき、損失は青天井になりません。

## 8. 調達の設計

### 8.1 これは「借入」の案件です

投下資本利益率が年200%規模なら、**年利10〜15%で借りて差額を全部取るのが圧倒的に合理的**です。出資者側から見ても、物販に株で入るより貸すほうがリスク調整後リターンが良い。

「なぜ銀行や日本政策金融公庫ではなく、うちなんですか？」は必ず聞かれます。答えは2つのどちらかで、混ぜると整合性が崩れます。

| | ストーリー |
|---|---|
| **A. 借入（推奨）** | 「銀行は実績のない越境ECに在庫担保では貸さない。最初の1年の実績を作る**つなぎ**。実績ができたら借り換える」 |
| **B. 出資** | 「物販は単体で儲けるためではなく、Coupang越境ECの運用フローを実証するため。売り物はその先の **Compass**（システム＋フランチャイズ）」 |

## 9. 実行前に潰すこと（優先順）

1. **卸契約書に越境販売・海外転売・再販地域の制限条項がないか**（すべての前提）
2. **韓国Coupang上で、柱1〜3の対象SKUの直購実勢価格・出品者数・推定販売数量を1〜2週間実測**
   → §5の損益分岐売値の列と突き合わせる。**これが本資料で唯一残った検証課題**
3. Dyson OnTrac の**充電器が100-240V対応か**を現物で確認（対応でなければ柱2は消える）
4. リファ ファインバブルの**韓国の給水ホース規格（G1/2）互換性**の確認
5. 会員限定14／定期購入45／予約48 SKU の**転売可否**をMTGに確認
6. セット品（花嫁セット等）の**中身に100V機器が含まれていないか**の確認
7. 輸出免税による仕入消費税の還付可否（税理士確認）
8. 韓国の関税率（HSコード：シャワーヘッド／ヘッドホン／アパレルで別）とRCEP軽減の可否
9. 国際送料の実見積（国際eパケット／EMS／DHL、重量帯別）
10. 為替レートを実勢値に更新（本資料は ¥1=₩9.5 の仮置き）
